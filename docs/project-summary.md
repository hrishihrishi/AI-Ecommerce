## AI tools used

The application uses the following AI and retrieval stack:

- Google Gemini models for embeddings and chat generation
- LangChain for prompt orchestration and tool calling
- LangGraph for conversational agent workflow and state transitions
- MongoDB Atlas vector search for semantic product retrieval
- MongoDB-based checkpoints for conversation persistence

## Project brief

Super Commerce combines a React + Next.js storefront with a Python FastAPI backend and an AI shopping assistant. The storefront handles user journeys such as product discovery, authentication, cart management, wishlist actions, and checkout. The AI layer helps users ask product-related questions using semantic and text search over the product catalog.
