## Project at a glance

Super Commerce is a full-stack e-commerce platform built with Next.js, FastAPI, MongoDB, and a LangGraph-powered AI shopping assistant. It supports catalog browsing, searching, cart and wishlist management, checkout, and AI-assisted product discovery.
